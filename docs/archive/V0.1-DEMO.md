# EHF 患者数据钱包 · v0.1-demo 版本说明

## 一、页面清单

### 公共
| 路径 | 说明 |
|------|------|
| `/` | 首页，三端入口（患者端 / 研究者端 / 管理后台） |
| `/login` | 登录（邮箱+密码，mock 用户） |
| `/register` | 注册（mock，提交后跳转登录） |

### 患者端（/patient/*）
| 路径 | 说明 |
|------|------|
| `/patient/dashboard` | 患者首页（DID、档案摘要、资料统计、快捷操作、可参与研究、最近授权） |
| `/patient/records` | 健康档案列表（筛选、搜索、上传入口） |
| `/patient/records/[id]` | 健康档案详情（标题、类型、日期、医院、摘要、文件说明） |
| `/patient/upload` | 上传资料（表单提交写入 mock store） |
| `/patient/studies` | 研究项目列表（筛选、卡片列表） |
| `/patient/studies/[id]` | 研究项目详情 +「授权参与」 |
| `/patient/consents` | 授权记录列表 |
| `/patient/consents/[id]` | 授权详情 |
| `/patient/settings` | 账户与隐私（占位） |

### 研究者端（/researcher/*）
| 路径 | 说明 |
|------|------|
| `/researcher/dashboard` | 研究者首页（项目数、已授权患者数、待处理请求、快捷操作、最近动态） |
| `/researcher/projects` | 项目列表（Table + 已授权人数，来自 store） |
| `/researcher/projects/new` | 创建研究项目（表单 mock 提交） |
| `/researcher/projects/[id]` | 项目详情（基本信息、纳排标准、所需资料、已授权患者入口） |
| `/researcher/projects/[id]/patients` | 已授权患者列表（DID、疾病、确诊时间、授权范围、资料摘要） |
| `/researcher/patients/[patientId]` | 患者资料摘要（按 DID，脱敏） |
| `/researcher/requests` | 资料请求（占位） |

### 管理后台（/admin/*）
| 路径 | 说明 |
|------|------|
| `/admin/dashboard` | 系统概览（患者/研究者/项目/授权统计、最近操作日志） |
| `/admin/patients` | 患者管理（Table，脱敏） |
| `/admin/researchers` | 研究者管理（Table + 通过/驳回） |
| `/admin/projects` | 项目管理（Table） |
| `/admin/records` | 资料审核（Table） |
| `/admin/consents` | 授权记录（Table，来自 store） |
| `/admin/audit-logs` | 审计日志（Table） |

## 三、演示流程（v0.1-demo）

1. 打开 `/`，点击「患者端」→ 进入登录，使用 patient@example.com / password 登录。
2. 患者端：上传资料（/patient/upload）→ 健康档案出现新记录；进入研究项目详情 → 点击「授权参与」→ 授权记录出现新授权。
3. 退出，使用 researcher@example.com 登录：我的项目 → 某项目「患者列表」→ 可见该患者 DID 与资料摘要；可进入「资料摘要」查看脱敏资料。
4. 退出，使用 admin@example.com 登录：授权记录可见上述授权；系统概览授权数更新。

## 四、技术栈与目录约定

- **框架**：Next.js 14（App Router）、React、TypeScript
- **样式**：Tailwind CSS、shadcn/ui（Card、Button、Table、Badge、Input、Label、Sheet 等）
- **布局**：`components/layout`（AppSidebar、AppTopbar、RoleLayoutShell、PageSection）
- **认证**：`context/AuthContext`；路由守卫 `components/auth/AuthGuard`
- **Mock 状态**：`context/MockStoreContext`；静态数据 `lib/mock/*`
- **导航**：`config/navigation.ts` 三端 navItems，侧栏统一「返回首页」链接 `/`
