# EHF 中国 POC 产品需求文档 PRD v1

Version: v1.0  
Date: 2026-03  
Product: **EHF Patient Data Wallet（中国 POC）**

## 一、项目背景

全球医疗数据长期由医疗机构、平台或研究机构掌握，患者在数据共享与研究使用中的参与度极低。与此同时，罕见病患者由于样本分散、数据不完整，研究推进困难。

EHF 项目的目标是构建一个 **以患者为中心的健康数据管理与共享平台**，使患者能够：
- 自主管理个人健康数据
- 自主授权数据参与科研
- 透明了解数据使用情况
- 从科研合作中获得潜在收益或权益

中国 POC（Proof of Concept）阶段将开发一个 **双端 Web MVP**，完成患者数据管理与研究授权的完整流程。首期系统不涉及区块链技术，仅预留未来 DID 与链上授权扩展接口。

## 二、产品目标

### 1. 技术目标
验证以下技术流程可行：
患者数据上传 → 数据整合为健康档案 → 研究者发布研究项目 → 患者授权参与研究 → 研究者查看授权患者数据

### 2. 产品目标
构建以下三类系统：
- **患者端（Patient Portal）**：用于患者管理个人健康数据与授权
- **研究者端（Research Portal）**：用于研究者发布研究项目与获取授权数据
- **管理后台（Admin Portal）**：用于系统审核与运营管理

### 3. 业务目标
验证以下模式：
- 患者数据自主上传
- 患者主动授权数据使用
- 数据使用全流程可审计

## 三、产品范围

### 包含功能
- 患者注册
- 健康档案管理
- 病历上传
- 研究项目发布
- 患者授权参与研究
- 研究者查看授权数据

### 不包含功能
- 区块链上链
- 智能合约
- 真实数据交易
- 收益分配系统
- 医院数据接口
- 自动 AI 医疗数据结构化

## 四、系统角色

### 1. 患者
系统核心用户。
能力：
- 创建健康身份
- 上传健康资料
- 管理健康档案
- 查看研究项目
- 授权研究项目使用数据

### 2. 研究者
科研机构、药企或学术机构研究人员。
能力：
- 创建研究项目
- 定义纳入标准
- 查看授权患者数据
- 请求补充资料

### 3. 管理员
系统运营与审核角色。
能力：
- 审核研究者
- 审核资料
- 管理项目
- 查看审计日志

## 五、核心业务流程

### 1. 患者建档流程
患者注册 → 系统生成健康身份 DID → 填写个人信息 → 上传健康资料 → 系统整合健康档案 → 患者查看健康档案摘要

### 2. 研究者发布研究流程
研究者注册 → 管理员审核 → 创建研究项目 → 填写项目详情 → 发布研究项目 → 患者可查看

### 3. 患者授权流程
患者浏览研究项目 → 查看研究详情 → 查看所需资料类型 → 选择授权范围 → 提交授权 → 系统记录授权日志 → 研究者获得访问权限

## 六、系统模块设计

### 1. 患者端
#### 用户账户
- 注册
- 登录
- 账户信息管理

#### 健康身份
- 创建 DID
- 查看 DID
示例：`did:ehf:cn:patient:8f4a2c91`

#### 健康档案
- 健康档案概览
- 病历时间轴
- 资料分类浏览

资料类型包括：
- 门诊记录
- 出院小结
- 检查报告
- 影像资料
- 基因检测
- 用药记录
- 其他

#### 病历上传
支持上传：
- PDF
- JPG
- PNG

上传流程：
选择资料类型 → 填写资料信息 → 上传文件 → 保存

#### 健康摘要
系统根据资料生成：
- 诊断信息
- 确诊时间
- 疾病类型
- 治疗历史

MVP 阶段为人工填写 + 简单摘要。

#### 研究项目
展示可参与研究项目：
- 项目名称
- 研究机构
- 疾病方向
- 纳入标准
- 需要资料

#### 授权管理
患者可：
- 授权参与研究
- 撤回授权
- 查看授权历史

### 2. 研究者端
#### 研究者账户
- 注册
- 机构信息
- 研究方向

#### 研究项目管理
创建研究项目字段包括：
- 项目名称
- 研究机构
- 研究简介
- 目标疾病
- 纳入标准
- 排除标准
- 需要资料类型
- 授权期限

#### 患者列表
查看已授权患者：
- 患者 DID
- 疾病类型
- 资料摘要

研究者不可查看患者真实身份信息。

#### 数据查看
可查看：
- 患者资料摘要
- 授权范围内资料

#### 资料补充请求
研究者可请求：
- 更多检查
- 更多病历

患者可选择是否提供。

### 3. 管理后台
管理员功能包括：
- 用户管理
- 研究者审核
- 研究项目管理
- 病历审核
- 授权记录管理
- 审计日志查看
